# Vendored from Kuber Mehta's "I didn't set a cookie"

Everything in this folder is copied from [Kuberwastaken/cookie](https://github.com/Kuberwastaken/cookie)
by [Kuber Mehta](https://kuber.studio), via the `shourya0523/cookie-OPED` fork, under the modified
MIT license in `LICENSE`. The probes (`probes/`) and the plain-English inferences (`infer/`) are
unchanged; Privacy Theater only calls them and renders the result in its own way.

The license requires visible credit in the deployed page, not just here. The page credits
Kuber by name with a link to the original project in Act I (where the live reading runs)
and again in the curtain call. Keep both if you change the page.

Only the passive probes run. The invasive tier (local port scan, WebRTC, extension
enumeration, permission sweep) and the evercookie in `persist.ts` are not used.
